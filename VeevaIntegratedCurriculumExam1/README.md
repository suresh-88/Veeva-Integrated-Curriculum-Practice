## Running the project

1.  Clone or download this repository.
2.  Open the `VeevaIntegratedCurriculumExam1` folder in IntelliJ IDEA
    (or another Java IDE).
3.  Allow Maven to resolve the dependencies from `pom.xml`.
4.  Open the required Java class and run it.

**Prerequisites:** JDK and Maven. For the Selenium scripts, a compatible
browser and browser driver are also required.
