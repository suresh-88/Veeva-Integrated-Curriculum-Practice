# Week 1 – Software Development Life Cycle (SDLC) & Agile Project Management

## Overview

During Week 1 of my Veeva Systems Automation Engineer training, I learned the fundamentals of the Software Development Life Cycle (SDLC), explored different SDLC methodologies, and gained hands-on experience with **Agile project management using Jira and test management using the Xray plugin**.

The focus was on understanding how software development teams plan, develop, track, test, and deliver software through structured workflows.

---

## 1. Theoretical Learning

### Software Development Life Cycle (SDLC)
- Introduction to SDLC and its importance in software development.
- Different SDLC models and their approaches.
- Waterfall Model – phases, workflow, advantages, and limitations.
- Agile vs. Waterfall – differences, flexibility, and practical use cases.

### Agile Methodology & Scrum
- Introduction to Agile methodology and its principles.
- Understanding the Scrum framework.
- Scrum roles and responsibilities.
- Scrum meetings and their purpose.
- Sprint planning and execution.
- Product Backlog and Sprint Backlog.
- Sprint Life Cycle – from planning to completion.

---

## 2. Hands-on Experience with Jira

Explored and worked with **Jira** to understand how software development projects are managed and tracked in real-world environments.

### Activities Performed
- Created and organized project work items.
- Created Epics, Stories, and Tasks.
- Added descriptions and relevant details to work items.
- Assigned Story Points.
- Established parent-child relationships between work items.
- Used labels to categorize and organize issues.
- Managed work item statuses throughout the development workflow.
- Explored Jira boards and project management features.

### Workflow Customization

Experimented with issue transitions and created custom workflow states to understand how work progresses through different stages.

**Workflow implemented:**

`TO DO → IN PROGRESS → DEVELOPMENT → TESTING → REVIEW → DEPLOYED → COMPLETED`

---

## 3. Hands-on Experience with Xray Plugin

Explored and used the **Xray Test Management plugin for Jira Cloud** to understand test management and the relationship between different testing entities.

### Activities Performed
- Created Test Cases.
- Defined Preconditions for test cases.
- Added test steps and expected results.
- Created Test Sets to organize test cases.
- Created Test Plans to plan testing activities.
- Created Test Executions to execute and track test cases.
- Established relationships and links between testing entities and project requirements.
- Explored the Xray testing hierarchy and workflow.

### Xray Test Management Hierarchy

`Requirements → Test Cases → Test Sets / Test Plans → Test Executions`

## 5. Key Takeaways

By the end of Week 1, I gained an understanding of:

- How software development progresses through different SDLC models.

- How teams manage requirements, tasks, and development progress using Jira.
