Streams in Java Introduction:
	The concept of streams is introduced from java 8 onwards and they provide a declarative and functional style approach to process the data stored in collections, arrays and io channels without modifying the original data, that means the data source or input for streams is data stored in collections, arrays and io channel. A stream is not a data structure and does not store data instead it takes data from a data structure like collection, list, set, array sequentially and acts as a pipeline for the data and performs computational operations. It performs two different types of computational operations in the pipeline :
i.  Intermediate operations
ii. Terminal operations
	the results generated at terminal operations will be transferred as output.
The following intermediate operations a stream pipeline can perform
filter
map
flatMap
sorted
distinct
peek

The following are terminal operations
collect
forEach
reduce
count
findFirst
				     stream
	       --------------------------------------------------
Data Source -> | Intermediate operations -> Terminal operations | -> Output
	       --------------------------------------------------
